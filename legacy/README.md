# Applications d'origine

Ce dossier conserve le code des applications avant unification, à titre de
référence historique. **Elles ne sont plus maintenues** : leurs fonctions sont
reprises par la plateforme (voir [`../docs/MIGRATION.md`](../docs/MIGRATION.md)).

| Dossier | Origine | Remplacé par |
|---|---|---|
| `openbuildings-streamlit/` | `pratisig/Openbuildings` | `/api/buildings/*` + interface unifiée |

Les dépôts non fusionnés ici (`floodingsn`, `innondationSN`, `Carto-facileSN`,
`openbuildings_app`) restent consultables sur GitHub ; leur logique utile a été
portée dans `apps/api/pratisig_api/modules/`.
